História da Internet

A Internet é uma rede mundial de computadores e dispositivos conectados para compartilhar dados e informações. Cada computador conectado possui um IP (Internet Protocol), que funciona como um identificador dentro da rede.

A Internet surgiu nos Estados Unidos, na década de 1960, a partir da ARPANET, inicialmente criada para interligar centros militares de comando e aumentar a segurança das comunicações diante da possibilidade de um ataque nuclear. Durante as décadas de 1970 e 1980, passou também a ser utilizada para fins educativos e culturais.

No Brasil, a Internet chegou em 1989, inicialmente conectando universidades como USP, UNICAMP e UNESP. Em 1995, passou a ser aberta também para usos culturais e comerciais.

Estrutura Básica do HTML

HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para estruturar páginas da Web.

Tags do HTML

As tags do HTML são elementos que definem a estrutura e o conteúdo de uma página web. Algumas das tags mais comuns incluem:

Tabelas

  • "table" → cria a tabela.
  • "tr" → cria uma linha da tabela (table row).
  • "td" → cria uma célula da tabela (table data).

O "rowspan" determina que uma célula deve ocupar mais de uma linha da tabela e o "colspan" determina que uma célula deve ocupar mais de uma coluna da tabela.

DIV

A tag "div" é utilizada para organizar e dividir o conteúdo da página em blocos, sendo muito utilizada na construção do layout.

Assim, o HTML organiza a estrutura da página e o CSS pode determinar como esses blocos serão apresentados visualmente.

ID e CLASS

O ID identifica um elemento específico e no CSS é representado por #.

A class pode ser utilizada para identificar um grupo de elementos que compartilham uma característica.

No CSS, a classe é representada por ".".

CSS: interno, externo e inline

O CSS interno fica dentro do próprio arquivo HTML, utilizando a tag "style".
Normalmente fica dentro do "head".

O CSS externo fica em um arquivo separado, normalmente em extensão ".css", que é ligado ao HTML. A vantagem é poder utilizar o mesmo arquivo CSS para várias páginas.

O CSS inline é o estilo colocado diretamente no elemento HTML. É colocado diretamente na tag.

Imagem

A tag "img" é utilizada para inserir uma imagem.

O atributo "src" indica o caminho/endereço da imagem que será carregada.

Hiperlink

Um hiperlink é um elemento que permite ao usuário acessar outro endereço ou recurso ao clicar.

URL - endereço de um recurso

  • Protocolo: indica como o recurso será transferido.
  • Domínio: indica o servidor/máquina onde o recurso está.
  • Pasta/diretório: indica onde o arquivo está dentro do servidor.
  • Recurso: é aquilo que queremos acessar, como uma página HTML, imagem, música ou outro arquivo.
